# Sairaj LLP — Corporate Website

Responsive industrial and logistics website with 28 content pages, ten service detail pages, migrated company articles, inquiry handoff and SEO metadata. Built with React, TypeScript, Tailwind and the existing TanStack Start integration.

Run `npm install`, then `npm run dev`. Validate with `npm run check`, `npm test` and `npm run build`. With the dev server on port 5173 and Chrome installed, run `npm run test:browser` for desktop/mobile checks.

See [CONTENT-MIGRATION.md](CONTENT-MIGRATION.md) for verified sources, missing company information, form integration points and publishing notes. Preview screenshots and browser results are in `qa/`.
