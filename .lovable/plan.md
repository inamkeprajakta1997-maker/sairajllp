# SAIRAJ LLP Website

Build a premium, responsive multi-page Sairaj LLP website using the uploaded brief and verified information from `sairajgroups.in`.

## What to build
- Create a brand-focused home page, shared navigation/footer, and dedicated About, Services, Industries, Group Companies, Insights, Contact, and Business Inquiry pages.
- Build ten distinct service detail URLs backed by verified service descriptions and existing service imagery; include a related-service path and inquiry call to action on each.
- Preserve the existing Sairaj logo and verified contact details; use original industrial photography for the home page. Carry across published testimonials, group-company logo artwork, and insight listings without inventing company names or metrics.
- Use a polished green/orange visual system, responsive navigation, accessible interactive links and forms, and page-specific title/description/social metadata.
- Keep inquiry submissions transparent: open a pre-addressed email draft for the verified company email; do not imply a backend has delivered or stored a message.
- Include a crawler sitemap and the actual deployed app origin in links only where it is verifiable; the project currently has no published URL.

## Technical approach
- Use existing TanStack Start file-based routes and shadcn Button; do not add React Router or an unapproved backend.
- Centralize verified company content and service/article data; use shared page components and typed dynamic detail routes.
- Add a test that verifies the ten service records requested in the brief. Preserve source files and generated-image assets within the project.

## Known source limitations
- The existing group page URL is a 404. The homepage has an unlabeled logo collage, not verifiable company names or outbound URLs.
- The old contact page has no readable form fields; its displayed generic quote form only exposes name, email, subject, and an optional message. No separate shipment fields or shipment workflow could be confirmed.
- The existing site has no published mission/vision/core-value copy or complete group-company descriptions. Do not fabricate these.
- Vehicle/forklift rental page could not be retrieved. Use the published service title/summary and mark no unavailable detailed claims as verified.
